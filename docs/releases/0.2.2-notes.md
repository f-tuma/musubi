## Changes

- Share one task across multiple calendars. Its home calendar controls editing and completion; linked calendars read the same task and progress. Independent copies have their own home and identity.
- Redesigned web settings, calendar controls and editors use one design system. Notifications in the top bar collect changes and delivery problems; server refresh is available in the sidebar.
- Harden mobile save acknowledgements, task refresh and session changes. Updating the native app requires signing in again because server-specific credential storage is now isolated without ambiguous legacy keys.
- Improve Google authentication recovery and CalDAV discovery handling. Outlook event and recurring-event operations remain subject to provider support and existing server feature gates.

## Upgrade requirements

Deploy matching API and web artifacts from this release. A new **0.2.2 mobile build is required for all task writes**, including ordinary task creation, completion and deletion. Installed 0.2.0/0.2.1 clients keep task reads and compatible calendar/event features, but task writes receive an update message before saving. Use the updated web app until the mobile update is available. iOS remains a TestFlight beta; its update action links to the existing beta channel. The global client and federation floors remain 0.2.0.

Microsoft To Do supports independent task copies where ordinary creation is supported. New live shared-task links to Microsoft To Do are excluded because conditional-write behavior is not verified.

Stop the previous API before starting 0.2.2. Its startup applies migrations 0079–0084. Keep a verified preupgrade database backup and the previous API/web image digests: **an image-only downgrade is unsafe after the task migration**. Restoring the database does not undo changes already delivered to providers.

Production inventory, live provider tests and tests on the actual mobile artifacts must be recorded separately from automated checks. No additional provider feature gate should be enabled during this upgrade. See the [release runbook](https://github.com/frgtn-dot-dev/musubi/blob/v0.2.2/docs/releases/0.2.2.md) for deployment and mobile instructions.
