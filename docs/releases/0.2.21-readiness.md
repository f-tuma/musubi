## Verified against `v0.2.20`

Checked with `git diff v0.2.20..3ebcb1c`: the only changed file is
`apps/web/Dockerfile`, build stage. It copies the `sentry-cli` binary resolved
through `apps/web`'s `@sentry/cli` (3.8.2) instead of the hoisted root copy
(2.58.4). A local `docker build --target build` printed `sentry-cli 3.8.2` for
the copied binary.

- **Database.** No migration; the journal still ends at `0087_project_news`.
- **Configuration.** No new or changed variables.
- **Types and protocol.** Only `PRODUCT_VERSION` changes (0.2.20 → 0.2.21).
  `MIN_CLIENT_VERSION` and `MIN_PEER_VERSION` stay `0.2.0`; the wire contract
  and task protocol are unchanged.
- **API image.** No source change beyond the version string.
