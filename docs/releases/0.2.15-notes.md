# Musubi 0.2.15

- Fixed Google token refresh interrupting calendar writes and sync when unchanged
  permissions were returned in a different order or format.
- Added private-data-safe diagnostics for unexpected event permission-check failures.

This API/web maintenance release works with existing mobile apps. No database
migration or new mobile build is required. Client and federation minimums remain
0.2.0; the task mutation protocol is unchanged. Improved native timeout wording
and HTTP error handling are included in source and arrive with the next mobile
store update.
