# Musubi 0.2.21

- The web image now carries the 3.x `sentry-cli` the web app declares, which
  uploads source maps as artifact bundles by debug ID. 0.2.20 shipped the 2.x
  binary, which fell back to release-based upload and failed against Rustrak
  with "Release not found". An upload against Rustrak from the published image
  has not been exercised yet.

This web-image fix needs no database migration, configuration change or new
mobile build. Client and peer minimums stay 0.2.0, and the task protocol is
unchanged.
