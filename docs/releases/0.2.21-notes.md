# Musubi 0.2.21

- The web container's source-map upload works against Rustrak. 0.2.20 shipped
  the 2.x `sentry-cli`, which fell back to release-based upload and failed with
  "Release not found"; the image now carries the 3.x binary the web app
  declares, which uploads artifact bundles by debug ID. Browser stack traces
  read as original source once `SENTRY_URL`, `SENTRY_AUTH_TOKEN` and
  `SENTRY_WEB_PROJECT` are set.

This web-image fix needs no database migration, configuration change or new
mobile build. Client and peer minimums stay 0.2.0, and the task protocol is
unchanged.
