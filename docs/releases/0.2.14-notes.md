# Musubi 0.2.14

- Fixed initial iCloud imports failing when an account has many calendars.
- Fixed calendar imports rejecting HTML text inside event notes.
- Large CalDAV calendars now load in smaller batches, with complete validation
  before imported changes are applied.
- Pending initial sync is reported separately from a failed import.
- Updated web support links and service email branding for Filip Tůma.

This API/web maintenance release works with existing mobile apps. No new mobile
build or database migration is required. Client and federation minimums remain
0.2.0; the existing task mutation protocol remains unchanged. Native support
contact changes arrive with the next store update.
