# Musubi 0.2.16

- Improved event creation and delivery while background sync for the same
  connected account is paused.
- Kept a bounded place for writes when that account's background queue is full.

Provider rate limits, permission checks and write ordering remain enforced.
This API/web maintenance release works with existing mobile apps and requires
no database migration or new mobile build. Client and peer minimums remain
0.2.0; the task mutation protocol is unchanged.
